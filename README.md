# Rubbish-For-Rewards
 
## Project Description
Rubbish-For-Rewards is a simulation website designed to teach people about waste management, while also keeping it fun by collecting and submitting trash and obtaining rewards in return.
 
## High-Priority Features
1. Student registration
2. Service request submission
3. Request status tracking
4. Request history
5. Administrative dashboard

## Technologies Used
- Python
- Streamlit
 
## OOP Implementation
- Polymorphism: Different classes using the same method name with different behaviors.
- Abstraction: Creating classes that hide complex implementation details.
 
## Project Structure
- app.py: Main Application
- assets/: Assets, including background
- controllers/: Application operations
- repositories/: Database access
 
## Installation
1. Download or clone the repository
2. Open Project folder
3. Install Dependencies
4. Run the application
