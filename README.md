# Rubbish-For-Rewards
 
## Project Description
Rubbish-For-Rewards is a simulation website designed to teach people about waste management, while also keeping it fun by collecting and submitting trash and obtaining rewards in return.
 
## High-Priority Features
1. Student registration
2. Service request submission
3. Request status tracking
4. Request history
5. Administrative dashboard

## Technologies Used
- Python
- Streamlit
 
## OOP Implementation
- Encapsulation: Request status is controlled by methods.
- Inheritance: Student and Staff extend User.
- Polymorphism: Different users have different permissions.
- Abstraction: Controllers hide internal processing steps.
 
## Project Structure
- models/: Application classes
- views/: User interface
- controllers/: Application operations
- repositories/: Database access
 
## Installation
1. Download or clone the repository.
2. Create and activate a Python environment.
3. Install the required packages.
4. Configure the application.
5. Run the main Python file.
